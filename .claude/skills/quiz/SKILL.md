# Quiz

Argument: temat lub folder (np. `pętle`, `09-DictionariesStacksAndQueues`, `wszystko do Test2`). Opcjonalnie liczba pytań (domyślnie 5).

## Kroki
1. **Zbierz materiał** z odpowiednich `_Temat.md` i notatek studenta (`notatki.md`). Dla „do TestN” – weź tematy z folderów przed tym testem.
2. **Zadawaj pytania pojedynczo** i czekaj na odpowiedź. Mieszaj typy:
   - „Co wypisze ten kod?” (krótki fragment),
   - „Znajdź błąd”,
   - „Napisz 2–5 linii, które…”,
   - pytanie pojęciowe („czym różni się lista od krotki?”).
3. Zacznij łatwo, podnoś poziom, jeśli idzie dobrze; obniżaj, jeśli nie.
4. **Po każdej odpowiedzi:** ✅/❌ + krótkie wyjaśnienie dlaczego. Przy kodzie – możesz go uruchomić, żeby pokazać faktyczny wynik.
5. **Na końcu:** wynik, lista tematów do powtórki i propozycja `/wyjasnij <temat>` dla najsłabszego punktu.
